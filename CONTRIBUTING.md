# Contributing to Daylight

Thanks for helping improve Daylight. The easiest contributions are clear bug reports and small, focused fixes.

## Report a problem

Open a GitHub issue with your Node.js version, what you expected, what happened, and steps to reproduce it. Include a screenshot only if it contains no private data. Never post API keys, OAuth tokens, Firebase service accounts, receipts, or personal workspace records.

## Make a change

1. Fork the repository and create a branch.
2. Follow the [quick start](README.md) with your own Firebase project.
3. Keep changes focused. Run `npm run lint` and `npm run build` before opening a pull request.
4. Explain the change and how you tested it in the pull request.

Optional integrations may require developer app approval. A basic workspace should continue to work without them.
